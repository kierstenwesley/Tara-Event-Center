# Tara Event Center Website

A responsive static website built for GitHub Pages.

## What is included

- `index.html` — landing page
- `contact.html` — contact/inquiry page
- `styles.css` — all styling
- `script.js` — mobile menu, gallery lightbox, and inquiry form behavior
- `assets/images/` — optimized event photos
- `assets/videos/` — web-ready MP4 videos

## Contact form behavior

Because GitHub Pages is a static host, this version does not require a server or paid form service. When a visitor fills out the form and clicks **Create Text Inquiry**, the site opens a pre-filled text message to **(770) 855-8445** with their event details.

This works especially well for mobile visitors. If you later want form submissions delivered by email instead, you can connect the form to a service such as Formspree.

## Publish on GitHub Pages

1. Create a new GitHub repository (for example `tara-event-center`).
2. Upload all files and folders from this project into the repository.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. GitHub will show the live website URL after it deploys.

## Optional updates

- Add Tara Event Center's Instagram URL to the header/footer.
- Add pricing, deposit rules, availability rules, or booking policies.
- Add an email address and switch the inquiry form to email delivery.
- Connect a custom domain such as `taraeventcenter.com`.
